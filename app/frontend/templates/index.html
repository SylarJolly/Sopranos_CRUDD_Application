The Sopranos Character API

This site is the front end for a REST API about the characters of The Sopranos. The API is built with FastAPI and stores each character's name, actor, role, status, and the first and last season they appeared in.

Through this site you can browse the cast, view a single character, add a new one, edit an existing one, or delete one. Every action is sent to the API, which saves the changes in the database.
